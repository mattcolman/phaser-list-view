# Phaser List View - Logo Designs

This repository contains three logo design variations for the `phaser-list-view` project. Each design emphasizes different aspects of the library while maintaining a professional and modern aesthetic suitable for a developer-focused JavaScript library.

## Logo Variations

### 1. Primary Logo (`logo.svg`)
**Theme: List View Focus**
- **Design**: Circular container with scrollable list items
- **Features**: 
  - Blue gradient background representing the Phaser gaming ecosystem
  - Horizontal list items showing the core functionality
  - Motion blur effects on partially visible items (representing culling/performance)
  - Scroll indicators showing directional movement
  - Clean, professional appearance
- **Best for**: Main repository display, documentation headers, npm package

### 2. Carousel Logo (`logo-carousel.svg`)
**Theme: Swipe Carousel & Interactive Elements**
- **Design**: Card-based carousel interface
- **Features**:
  - Purple gradient background for modern tech aesthetic
  - 3D perspective cards showing swipe carousel functionality
  - Swipe arrows indicating touch/gesture support
  - Page indicators showing navigation state
  - Phaser-style accent element
- **Best for**: Marketing materials, demo showcases, carousel-specific documentation

### 3. Minimal Logo (`logo-minimal.svg`)
**Theme: Performance & Technical Excellence**
- **Design**: Clean, technical interface representation
- **Features**:
  - Light background for versatility
  - Dynamic list items with varying content lengths
  - Performance indicators (60fps display)
  - Scroll bar visualization
  - Physics/momentum curve indicator
  - Touch gesture symbol
- **Best for**: Technical documentation, GitHub social preview, developer presentations

## Usage Guidelines

### File Formats
- All logos are provided in SVG format for infinite scalability
- Suitable for web, print, and high-DPI displays
- Can be easily converted to PNG/JPG if needed

### Color Schemes
- **Primary Logo**: Blue-based palette (#4A90E2, #357ABD)
- **Carousel Logo**: Purple-based palette (#667EEA, #764BA2)
- **Minimal Logo**: Blue with green accents (#3B82F6, #10B981)

### Recommended Usage
- **GitHub Repository**: Use `logo.svg` as the main logo
- **npm Package**: Use `logo-minimal.svg` for clean, professional appearance
- **Documentation**: Any variation depending on the section focus
- **Social Media**: `logo-carousel.svg` for more engaging visual appeal

### Size Recommendations
- **Large displays**: 200px+ width
- **Medium displays**: 100-200px width  
- **Small displays/favicons**: 32-64px width
- **Social media**: 400x400px for square formats

## Technical Details

### Design Elements Represented
1. **List View Functionality**: Horizontal bars representing list items
2. **Scrolling Behavior**: Motion indicators, scroll bars, directional arrows
3. **Performance Features**: 60fps indicators, motion blur for culling
4. **Touch Interaction**: Swipe gestures, touch indicators
5. **Phaser Integration**: Color schemes and accent elements referencing the Phaser framework

### Accessibility
- High contrast ratios for readability
- Clear visual hierarchy
- Scalable vector graphics for all screen sizes
- Meaningful visual metaphors for functionality

## Implementation

To use these logos in your project:

```html
<!-- For web usage -->

<!-- For favicon -->

```
